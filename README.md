# GST 212 Practice Web App

A Next.js practice application containing 112 unique questions extracted and deduplicated from course materials (`GST COMP merged_merged.pdf`).

## Features

- **112 Deduplicated Questions**: 120 total question blocks extracted and cleaned into 112 unique multiple-choice questions.
- **Show Answer Toggle**: Click "Show Answer" under any question to toggle the correct answer.
- **Interactive Practice**: Select options (A, B, C, D) to test your knowledge.
- **Search & Filter**: Filter questions by keyword or question number instantly.
- **Jump to Question**: Quickly navigate directly to any question by number (1 to 112).
- **Responsive Dark Design**: Styled with modern glassmorphism panels, gradients, and clean typography.

## Getting Started

Run the development server:

```bash
bun dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
